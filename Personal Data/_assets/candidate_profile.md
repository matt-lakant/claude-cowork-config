## Voice & style guidelines (for resume/cover-letter generation)
- **Person:** Profile sections must NOT use third person ("Matt specializes…" or "Matt est un…" are forbidden). Prefer impersonal/participial constructions ("Specialist in…", "Spécialiste de…", "20+ years delivering…"). Use first person ("I" / "Je") only when a pronoun is genuinely unavoidable. Never use "I" in achievement bullets — implicit first person only ("Drove…", "Led…", "Designed…").
- **Header citizenship line:** Write "French citizen" (EN) or "Citoyen français" (FR). Do NOT add "EU work rights" — it is redundant. The citizenship line must be non-bold and the same font size as the contact line below it.
- **Tense:** Past tense for completed roles; present continuous for current ("Currently leading…").
- **Bullet structure:** Action verb → what was done → scope/scale → measurable result where possible.
- **Tone:** Professional, strategic, business-impact-led. Avoid hype words ("synergies", "rockstar", "ninja", "leveraged" as filler). Prefer concrete: "Drove 15% revenue growth" beats "Leveraged synergies for growth."
- **Sober by default (added 2026-06-20):** Draft sober and concise from the first pass. Cut filler, "cheesy"/marketing flourishes, and rhetorical asides. Avoid openers like "Coincidentally/Notably", framings like "X as a discipline, not a one-off", and "passionate/excited about" phrasing. The shorter, drier version wins. See feedback memory.
- **Avoid:** First-person pronouns in bullets; third-person pronouns anywhere; em-dashes inside bullets; over-formatting (bold inside bullets); fluff adjectives.
- **Numbers:** Always use figures (15%, ~60 accounts, 2002–2026) — never spelled out.

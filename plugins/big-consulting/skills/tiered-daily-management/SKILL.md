# Tiered Daily Management System

## What this produces
A tier structure, agendas, board designs, escalation rules, leader standard work, and a rollout plan for one pilot area.

## Inputs to ask for
- Org structure for the area (teams, supervisors, managers, site leader)
- Key measures from the redesign (volume, backlog, quality, lead time, safety)
- Shift schedules and current meetings
- Recurring problems from observation and root cause work
If no problem list exists, start one at the first huddle.

## Method
1. Set the tiers: Tier 1 team huddle at shift start; Tier 2 supervisors and manager next; Tier 3 site leaders. Each 10 to 15 minutes, standing, at the board.
2. Pick 3 to 5 measures per tier, mostly leading indicators the tier can influence today, shown as today vs target with red or green.
3. Fix the agenda: yesterday vs target, today's plan and staffing, problems, escalations, recognition.
4. Escalation rule: anything a tier cannot solve goes up the same day and gets an answer back down within 24 hours.
5. Problem log: problem, owner, date raised, due date, status. Problems older than a week escalate automatically.
6. Leader standard work: daily floor walks, huddle attendance, and one problem coached to closure per week.
7. Pilot in one area for six weeks, then audit huddle quality before expanding.

## Output format
- Tier table: Tier | Attendees | Time | Duration | Measures
- Agenda script per tier
- Board layout as a text sketch
- Escalation rules and problem log columns
- Leader standard work: Role | Daily | Weekly
- Pilot plan with audit checklist

## Quality checks
- Every measure is one the tier can move today
- Escalations close the loop back down
- Huddles solve or assign problems; status stays on the board
- Leaders are on the floor daily

## Notes from the source article
- **Replaces:** The operating rhythm a lean team installs at the end of an engagement: daily huddles at team, supervisor, and site level, with boards and escalation so problems get solved within a day.
- **Example request:** “We just redesigned our warehouse picking process. Design a tiered daily management system for three shifts so the gains stick and problems stop sitting for weeks.”
- **What the user still owns:** Showing up. The system works only when leaders attend, answer escalations fast, and treat bad news from the floor as useful.
- When handing the deliverable back, name in one line the decision above that stays with the user.

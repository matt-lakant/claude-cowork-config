# Quarterly Value Review

## What this produces
A pre-read of four pages or fewer: portfolio value and spend, a call on each initiative, reallocation options, and three to five decisions for the executive team.

## Inputs to ask for
- Benefits tracker output and finance-confirmed actuals
- Portfolio budget: approved, spent, remaining by initiative
- Status and RAID summary per initiative; kill criteria from charters
- New funding requests and current strategic priorities
Label benefit numbers finance has not confirmed as "program-reported."

## Method
1. Portfolio totals: planned against realized value year to date, spend against budget, full-year forecast.
2. For each initiative compute remaining value, remaining cost, and remaining value per dollar. Ignore sunk cost.
3. Call each initiative: Accelerate (strong remaining value per dollar, capacity-constrained), Continue, Fix (behind with a credible fix), Stop (kill criteria met or remaining value below remaining cost).
4. Reallocate: move freed budget and people to the highest remaining value per dollar, checking team capacity.
5. Confidence-adjust the full-year forecast: high 90%, medium 60%, low 30% of forecast, labeled as the method.
6. Frame three to five decisions, each with options and a recommendation.

## Output format
- Portfolio summary: Planned value | Realized | Budget | Spent | Forecast
- Waterfall from planned to realized value by cause
- Initiative table: Initiative | Realized | Remaining value | Remaining cost | Value per dollar | Call | Reason
- Reallocation table: From | To | Amount | Expected value
- Decisions: Decision | Options | Recommendation | Owner

## Quality checks
- Every call uses remaining value and cost, never sunk cost
- Numbers tie to the benefits tracker and finance actuals
- Each decision has options and an owner
- Stop calls cite the kill criteria or the economics

## Notes from the source article
- **Replaces:** The quarterly portfolio review where executives see what the transformation delivered and cost, and what to stop.
- **Example request:** “The exec team meets next Tuesday. Here’s the benefits tracker, the portfolio budget, and initiative status. Build the quarterly value review and tell me what we should stop.”
- **What the user still owns:** Stopping something a peer sponsors. That is an executive act.
- When handing the deliverable back, name in one line the decision above that stays with the user.

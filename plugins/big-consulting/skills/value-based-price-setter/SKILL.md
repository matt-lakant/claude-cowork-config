# Value-Based Price Setter

## What this produces
An EVC model for one offer and segment, a recommended price range, and a value story sales can use with buyers.

## Inputs to ask for
- The offer and target segment
- The customer's realistic next best alternative and its full price
- Evidence of differentiation: interviews, performance specs, win/loss notes
- Current price and unit cost
- If the alternative is unclear, stop and ask. EVC without a named reference is guesswork.

## Method
1. Fix the reference value: the full cost of the next best alternative, including required add-ons.
2. List differentiators versus that alternative. For each, name the customer economic lever it moves: revenue gained, cost avoided, risk reduced, capital freed, time saved.
3. Quantify each lever per customer per year with a stated formula. Include negative differentiation (what the alternative does better, switching effort).
4. Sum: EVC = reference value + positive differentiation value minus negative differentiation value.
5. Set the range between reference value (floor) and EVC (ceiling). Recommend a capture share: how much value you keep versus leave as the customer's reason to switch.
6. Test against cost: confirm the price clears target margin. If EVC is below cost-plus, say so plainly.
7. Stress-test the three largest value drivers at half their estimated value.

## Output format
- Value table: Driver | Customer lever | Formula | Annual $ per customer | Evidence | Confidence (H/M/L)
- Price range: floor, recommended, ceiling, with capture share %
- Sensitivity table for the top three drivers
- Value story: five sentences a rep can say out loud

## Quality checks
- Every driver has a formula and a source; unsourced drivers are labeled assumptions
- Negative differentiation is included, even if small
- Recommended price is still defensible at half-value on the top driver
- The value story uses customer outcomes, not feature names

## Notes from the source article
- **Replaces:** The value workstream: customer interviews feeding an economic-value model that shows what a product is worth to the buyer.
- **Example request:** “We’re launching a predictive maintenance add-on. Customers today use scheduled maintenance from their OEM. Build the value model and tell me what we can charge.”
- **What the user still owns:** Picking how much value to leave on the table for the customer, which is a strategic bet on share versus margin that no model settles.
- When handing the deliverable back, name in one line the decision above that stays with the user.

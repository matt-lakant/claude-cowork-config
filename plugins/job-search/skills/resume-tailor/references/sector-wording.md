# Wording for an employer outside financial services (rule R4)

Read this when the brief carries the tag `non_finance`. Rule from Matt, 2026-10-08: rewrite the finance-specific wording of the whole CV, not only the new lines, in the first draft and without being asked.

## Method

Read `company_overview.md` and the posting for the employer's own vocabulary first, then describe what Matt's work was in those terms. FactSet's research production suite was software to **author, review (compliance), publish and distribute documents**. Say that in the employer's words:

| Employer | Wording |
|---|---|
| A workspace tool (Notion) | "collaborative authoring, review and publishing"; "templates, workflows, views" |
| An information-services publisher (Wolters Kluwer) | "expert content"; "professional workflow software" |
| Corporate-finance software (OneStream) | "financial data and reporting" |
| A data or master-data vendor (Semarchy) | "reference data", "master data", "data models and rules", "content and data production software" |
| A generalist group, in French | "production et publication de contenus" |

## Typical swaps

| Finance wording | Replace with |
|---|---|
| research production suite / software | the domain phrase above |
| AI-powered research authoring | AI-assisted report drafting; authoring of expert content |
| institutional accounts | enterprise accounts |
| index data platform for financial institutions | data platform |
| research databases for the investment teams | custom databases, internal knowledge bases, data warehouse for the client's teams |
| external managers (APG) | third parties |
| Goldman "research teams / tools" | "teams"; "internal tools and databases" |
| buy-side and sell-side services | two services organizations |
| securities, market data vendors | instruments, data vendors |
| RMS Partners, as a product description | "ERP for content production" (the name stays where it is a name) |

## What stays

- Job titles, the department name (Research Management Solutions) and client names.
- **One** sector mention, in the FactSet context line ("enterprise clients worldwide, mostly in financial services"), so the CV never reads as hiding the background.
- When the employer sells to finance functions (CPM, accounting software), the finance words that echo its product ("CFO", "financial data and reporting"). Sell-side jargon ("research", "brokers", "sovereign funds") still goes.

`cv_check.py` warns on the commonest finance terms under the tag `non_finance`. It does not judge whether the replacement echoes the employer: that is your reading.
